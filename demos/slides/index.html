av2codec · av2 v1.0.0 · demo

Four views.
One bitstream.
A canvas.

AV2 carries multiview as independent extended layers, described by a layer configuration record and an atlas that says where each layer lands. This demo encodes four layers — three synthetic sports feeds and your camera — into one AV2 multistream and composes them into a single 2×2 frame canvas.

  • LCR + atlas + MSDO metadata, no per-view container tricks
  • Every frame of the canvas is reconstructed from the AV2 bitstream
  • Runs entirely in the browser, no server, no native binaries

The encoder is av2codec compiled to wasm32-unknown-unknown; the decoder is the same crate's decoder. dav2d knows the OBU types but ignores LCR/atlas/MSDO, so it can only emit layers sequentially — composition always belongs to the player.

try it

Your camera,
layer 3

Scan the code, open the page, press Enable camera. The tab encodes your webcam together with the three feeds, decodes the multistream and paints the 640×384 canvas at 15 fps.

The hosted URL is HTTPS, so the camera works from any device that can reach it. Opening the files locally still works on http://localhost/; plain HTTP on a LAN address blocks the camera, and the page explains why.
